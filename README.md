# Simapex per PC

Programma per Windows che legge la telemetria di ACC, aiuta con il setup e fa da squadra al pilota.
Il vecchio Simapex per telefono è nel ramo `archivio-telefono-0.83`.

- Codice: `simapex/` (telemetria, setup, server locale, pagina)
- Prove automatiche: `python -m unittest discover -s tests`
- La costruzione del file `.exe` e la pubblicazione sono automatiche (GitHub Actions)
